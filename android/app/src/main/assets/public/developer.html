Mandatory Validation Specifications (No Silent Fallback Guessing):
  • Station Column: Must contain station (or station_name). Empty station values are rejected with 400 Bad Request.
  • Timestamp Column: Must contain timestamp (or datetime, observed_at). Standard ISO 8601 or CPCB DD-MM-YYYY formats accepted.
  • Pollutant Values: At least one pollutant column (pm2_5, pm10, no2, so2, co, o3, or aqi) is required. Rows with all empty pollutant readings or non-numeric strings are rejected.
  • Freshness Rules: Data is tagged with source = "CPCB_MANUAL". Only marked as LIVE if genuine observation is recent (<15m). Otherwise marked as AGING, STALE, or UNAVAILABLE.
